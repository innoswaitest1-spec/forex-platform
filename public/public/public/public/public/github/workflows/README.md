# InnoswaiFX Trading Platform

Advanced forex analysis website and mobile app.

## How to Use
1. Get a free API key from [twelvedata.com](https://twelvedata.com) and replace `YOUR_TWELVE_DATA_API_KEY` in `server.js`.
2. To run the website locally, install Node.js and run `npm install && npm start`.
3. Deploy this server for free on [Render](https://render.com) or [Vercel](https://vercel.com).
4. After deployment, update `capacitor.config.json` with your live URL.
5. Push to GitHub – the APK will be built automatically and available in the **Actions** tab.

## Features
- Real-time forex prices
- NY close breakout/reversal analysis
- Strategy recommendation (ORB, Wyckoff)
- Admin panel
- Academy, News, Subscription pages
- Android APK (via Capacitor)
